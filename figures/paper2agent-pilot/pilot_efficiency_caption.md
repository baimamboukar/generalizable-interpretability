**Paper-specific MCP assistance reduces agent cost and API time in two reproduction pilots.** Raw and MCP-assisted Claude Opus 5.5 conditions received the same study inputs and were evaluated on the same scientific task. Both conditions passed: each returned all 12 Lookback Lens AUROC values, and each recovered 9 of 12 unique Internal Instruction Following cells within 0.03 AUROC while identifying the instruction-type confound. Labels beside the MCP-assisted bars report the reduction relative to the raw-agent condition. Task wall time is excluded because the Lookback MCP session contained unmeasured idle time.
