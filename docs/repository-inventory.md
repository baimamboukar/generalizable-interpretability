# Repository Inventory

The [repository guide](../README.md) describes the current directory structure and Git policy. The [data guide](../data/README.md) describes retained evidence and screening results. Study reports are kept in `reports/`. Local experiment code remains in the ignored `replications/` directory.

Original author repositories and local run artifacts remain separate from tracked analysis code. Manuscripts, submission material, slides and planning drafts are maintained outside the repository.
