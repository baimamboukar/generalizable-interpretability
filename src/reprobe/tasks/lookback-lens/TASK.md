# Lookback Lens

Reproduce the released Lookback Lens probing experiment on Natural Questions and CNN/DailyMail. Evaluate the predefined-span and eight-token-window settings in both transfer directions.

Use only the supplied paper, repository, annotations, lookback-ratio features and tokenizer. Fit the probes during this run. Save runnable code, fitted probes, predictions, metrics, logs and a concise report under `./output`.
